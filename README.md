# HOF do Zero

Página de vendas do workshop HOF do Zero, da Dra. Isabella Crusciol.

## Sobre o projeto

O projeto apresenta a oferta do workshop ao vivo para estudantes em fase final de formação e profissionais que desejam começar na harmonização facial com mais clareza, direção e visão de negócio.

As três páginas de venda compartilham a mesma estrutura, identidade visual, oferta e componentes. Apenas a comunicação da abertura muda entre as rotas.

## Tecnologias

- React 19
- Vite 8
- CSS responsivo
- Vercel

## Rotas

- `/a1`
- `/a2`
- `/a3`
- `/obrigado`

## Execução local

